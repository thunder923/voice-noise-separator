# 声とノイズの分離ツール — Voice / Noise Separator

映画録音の整音を楽にするための、**「声だけ」と「ノイズだけ」を1つに統合した**ツール。
1回の処理で2つのステムを同時に出す:

- `*_VOICE.wav` … セリフだけ（ノイズ除去済み）
- `*_NOISE.wav` … ノイズだけ（原音 − 声。風・環境音・ルームトーン・ハム等）

**設計の肝**: NOISE は「原音 − VOICE」の残差で作るので、**VOICE + NOISE = 原音に完全に戻る**
（テストで最大誤差 1.5e-08 を確認済み）。
Pro Tools に2トラック並べれば、フェーダー2本で「セリフ vs 空気感」を
ミックス段階でいつでも再調整できる。消しすぎて後悔する事故が起きない。

## 3つの形態・全部入り（共通コア方式）

| 形態 | 中身 | 状態 |
|---|---|---|
| **Web版** | `app.py`（FastAPI）+ `static/index.html`。ドラッグ&ドロップ→試聴→24bit/48kHz WAV保存 | ✅ 動作検証済み |
| **Macアプリ版** | `mac/一発起動.command` — Web版と同じサーバーをローカル起動して Safari で開く（他の自作ツールと同じ方式） | 土台完成・Macコピー配置済み（Mac実機での初回起動確認はこれから） |
| **プラグイン版** | `plugin/` JUCE プロジェクト（VST3 / AU / AAX）。Voice Only / Noise Only / Blend の3モード | ⚠ ソース（スケルトン）のみ・未コンパイル（MacでJUCE導入後） |

全部の形態が同じ分離原理（`core/separator.py`）を共有するので、精度改善は1箇所直せば全部に効く。

## 起動方法（Mac）

1. **初回だけ**: `mac/AIセットアップ.command` をダブルクリック
   （.venv 作成＋基本ライブラリ＋PyTorch＋AIエンジン（MossFormer2 / DeepFilterNet3）を一括導入。数GB級のDLがあり時間がかかる）
   - AIエンジンなしで軽く試すだけなら、この手順は飛ばしてよい（自動で `spectral` 方式になる）
2. **通常起動**: `mac/一発起動.command` をダブルクリック → サーバーが立ち上がり Safari で http://localhost:8200 が開く
   - 既に起動中なら、ブラウザを開くだけ（多重起動しない）
   - サーバー直起動の場合: `.venv/bin/python app.py`（ポート 8200）
3. 終了: バックグラウンドで動き続けるので、止めたいときはアクティビティモニタ等で python プロセスを終了する。ログは `separator.log`

## 使い方（Web / Mac 共通）

1. ファイルをドロップ（動画でも可、音声だけ抽出される）
2. 分離エンジンと「分離の強さ」（0.7〜0.85 目安）を選ぶ
3. 必要なら「ノイズ別の先行修復」のチェックを調整する（下表参照）
4. 「分離する」→ 原音 / VOICE / NOISE を聴き比べて、24bit/48kHz WAV で保存

## ノイズ別の先行修復（`core/repair.py`・分離の前に効く）

「想定できるノイズ」ごとに専用処理を用意し、画面のチェックで個別ON/OFFできる。
修復で消した分は NOISE ステム側に残る（VOICE+NOISE=原音 は維持）。

| 対象（画面のチェック名） | 既定 | 処理 | 検証値（合成テスト） |
|---|---|---|---|
| 📶 ワイヤレスのパチパチ／ビリビリ（RFヒット） | ON | 予測誤差でインパルス検出（25msブロック適応閾値）→補間修復 | ピーク誤差 1.50 → 0.05。ノイズ混じりでも25個のクリックを検出 |
| 🔌 ハム／バズ（50/60Hz＋倍音） | ON | 無音部から電源周波数を自動検出→**無音部アンカー方式**でハム波形を合成して差し引く（ノッチで声を削らない方式） | RMS誤差 0.0706 → **0.0000**（声と倍音が重なっても声は無傷） |
| ✂️ ワイヤレスのドロップアウト（音切れ） | ON | 3〜250msの音切れを検出→直前のルームトーンで穴埋め | 60msの穴を修復（無音→RMS 0.20） |
| 🌬 風・吹かれ／低音のゴーッ | OFF（任意ON） | 80Hzハイパス | — |
| 🍃 環境音・ガサガサ（風景音／衣擦れ／部屋の定常ノイズ） | ON | 定常ノイズスペクトル推定＋Wienerゲイン（通常のノイズリダクション方式。セリフの下の環境音も一緒に抑える） | ベッド 0.161 → 0.058（無音部64%減）、セリフ下の誤差 0.159 → 0.075、声の保持 89% |

## 分離エンジン（3段階・用途で切替）

| エンジン | 特徴 | 向いている場面 |
|---|---|---|
| `spectral`（標準搭載） | ブロック最小統計ノイズ推定＋Wiener系ソフトマスク。モデル不要・軽量・48kHz | 下処理・大量クリップ・まず試す |
| `deepfilternet`（任意） | DeepFilterNet3。CPUで実時間の約5倍速、48kHzフルバンド | バッチ処理の本命候補 |
| `mossformer2`（任意） | MossFormer2_SE_48K（ClearerVoice）。論文値 PESQ 3.15 / SI-SDR 19.38 で3モデルの中では最高品質 | 本番のセリフ救済・最終整音 |

AIエンジン未インストールの環境では自動で `spectral` にフォールバックし、画面に明示する（黙って劣化させない）。

**AI導入状況（2026-10-27・全て無料・VMで実分離まで検証済み）**:
torch (CPU版) + ClearVoice + DeepFilterNet (Rust製拡張は rustup を入れてビルド) を導入。
DeepFilterNet 0.5.6 と現行 torchaudio の非互換（backend/info/load の削除）は
`core/separator.py` 内のシムで吸収済み。**torchcodec は入れないこと**（ネイティブlibが競合する）。
導入レシピは `requirements.txt` に記録。Mac では `mac/AIセットアップ.command` が同じ内容を一括実行する。

**エンジン比較（同一テスト音源: セリフ風音声＋風ノイズ、無音区間のノイズ 0.310 が基準）**
| エンジン | 無音部ノイズ → | セリフ保持（元の声 0.268） | 性格 |
|---|---|---|---|
| spectral（標準） | 0.0555（82%減） | 0.194 | 軽量・即時 |
| DeepFilterNet3 | 0.105（66%減） | 0.253 | 自然さ優先・高速。空気感を残す |
| **MossFormer2_SE_48K** | **0.0011（99.6%減）** | 0.251 | 最強の除去力。本番のセリフ救済向け（モデル読込に少し時間） |

## Pro Tools連携（2段構え）

1. **PTSL連携（今日から使える・承認不要）** — `protools/ptsl_bridge.py`
   Pro Tools 2022.12以降に無料で入っている Scripting SDK (PTSL) 経由で、
   開いているセッションへ VOICE / NOISE を自動インポートし、2トラックを作成する。
   `pip install py-ptsl` だけ。Pro Tools が無い環境では分離だけ実行してファイルパスを出す。
2. **AAXプラグイン（段階的に）** — 小売版AAXは Avid開発者承認＋PACE署名（物理iLok必須）が要るため、
   まず VST3/AU で完成させ、Developer版 Pro Tools で AAX テスト、最後に署名申請という順番。
   詳細は `plugin/README.md`。

## CLI
```
python3 -m core.separator 入力.wav 出力フォルダ [強さ]
python3 protools/ptsl_bridge.py 入力.wav --strength 0.8
```

## 検証結果（このVMで実施）
合成テスト音源（セリフ風ハーモニクス＋風ノイズ＋100Hzハム、6秒/48kHz）:
- 無音区間のノイズ: RMS 0.310 → VOICEステム内 0.055（約82%減）、その分は NOISEステム側へ
- セリフ区間: 声 RMS 0.268 → VOICE内に 0.194 を保持
- VOICE + NOISE と原音の最大誤差: 1.5e-08（=実質完全一致）
