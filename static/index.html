2設定



弱い＝声は自然だがノイズが残る／強い＝ノイズは減るが声が痩せて嘘っぽくなりやすい。既定は自然さ優先の 0.65


除去した音の一部を声へ混ぜ戻し、水っぽさ・金属っぽさ・無音の不自然さを抑えます。AIエンジンにも効きます（0＝混ぜ戻しなし）

🎚 仕上げ


BS.1770でミックス全体のラウドネスを測り、目標値に揃えます（ステム間のバランスは変えません。ピークが天井に当たる場合はゲインを抑えます）



プレビューの結果は元の位置（開始秒）に対応します。全編に戻すときは開始秒を目安にしてください

4結果

🔊 原音
🗣 声だけ（VOICE） ⬇ VOICE.wav を保存（24bit / 48kHz）
🌬 ノイズだけ（NOISE = 原音 − 声） ⬇ NOISE.wav を保存（24bit / 48kHz）

📝 セリフ書き出し（Whisper） 初回はモデルのダウンロードがあります。書き出しはこのマシンの中で処理します

VOICE + NOISE を足すと原音に完全に戻ります（検証済み）。Pro Tools に2トラックで入れて、 フェーダーバランスを変えるだけで「セリフ vs 空気感」を後から調整できます。 片方だけ書き出したい時もこの1画面で両方取れます。

🎛 波形エディタ （編集はこのブラウザの中だけ・対象ステムはクリックで切替）

対象:
スペクトログラム（対象ステム・左チャンネル）

カット／ペーストは全ステムの長さを揃えたまま編集します（対象ステムには音、他ステムには同じ長さの無音が入る）ので、ステム同士がずれることはありません。移動は同じ位置のまま別ステムへ足し込みます。

Pro Tools連携: protools/ptsl_bridge.py を使うと、開いているセッションへ VOICE / NOISE の2トラックを自動でインポート＆配置できます（詳細は README）。

📖 使い方

起動

  • Mac: mac/一発起動.command をダブルクリックすると、サーバーが起動して Safari でこの画面が開きます。
  • 直接起動: .venv/bin/python app.py → ブラウザで http://localhost:8200

基本操作

  1. 音声・動画ファイルをドロップ（またはクリックで選択）。動画は音声だけ取り出します。
  2. 分離エンジンと強さを選ぶ（迷ったらプリセット「🌿 自然」か「⚖️ バランス」。既定は自然さ優先＝強さ 0.65＋空気感の戻し 0.20 で、嘘っぽい除去感を避けます）。
  3. ノイズ別の先行修復は、気になるノイズのものだけ ON にする。
  4. 「分離する」→ 原音 / VOICE / NOISE を聴き比べて、それぞれの WAV を保存（24bit / 48kHz）。

保存先

  • 保存ボタンでダウンロードしたファイルは、ブラウザのダウンロード先に入ります。
  • 処理したファイルは、このツールの中の work フォルダにも残ります（下のプライバシー参照）。

注意点

  • 長いファイルや AI エンジンは処理に時間がかかります。
  • AI エンジン（DeepFilterNet / MossFormer2 / RE-USE）が入っていない環境では、自動で標準（spectral）に切り替わり、画面にその旨が表示されます。
  • RE-USE はノイズに加えて残響・音割れ・音質劣化まで修復する万能型ですが、CPUでは実時間の数十倍かかることがあります。短いクリップ向けです。
  • VOICE + NOISE を足すと原音に完全に戻るので、消しすぎても後からフェーダーで取り戻せます。
🔒 プライバシーポリシー
  • 音声・動画ファイルが外部へ送信されることはありません。分離・修復の処理は、すべてお使いのコンピュータの中だけで完結します（処理プログラムに外部へ送信する仕組み自体がありません）。
  • ブラウザからこのツールへ渡したファイルは、処理のためにツール内の work フォルダに保存され、結果の再生・ダウンロードもそこから行われます。サーバーを止めても自動では消えないので、不要になったら work フォルダの中身を削除してください。
  • AI エンジン（DeepFilterNet / MossFormer2 / RE-USE）の処理もこのマシンの中で実行されます。モデルのダウンロードはセットアップ（AIセットアップ）のときだけで、音声データが外に出ることはありません。
  • 作者への送信や、利用状況の収集（アクセス解析・テレメトリ）はありません。
  • この画面は同じネットワーク（自宅 LAN / Tailscale）内の端末からも開けます。パスワード等の認証はないので、信頼できるネットワークの中だけで使ってください。
